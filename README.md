# データベース入門研修・事前アンケート

GitHub Pagesで公開する受講者向け画面です。`docs/` が公開用のビルド成果物です。

## 公開内容

このリポジトリには画面・選択肢・スタイルのみを含みます。回答データ、講師アカウント、秘密鍵、APIキーは含みません。
回答は既存のアンケート用バックエンドへ送信され、講師用の認証された画面で確認します。GitHubリポジトリには回答を保存しません。

## 開発

Node.js 22以上で `npm install`、`npm run build` を実行します。
GitHub Pagesの公開元は `main` ブランチの `/docs` です。

専攻・資格を含むすべての設問は任意回答です。自動削除はまだ設定されていないため、画面には自動削除を保証する記載をしていません。
